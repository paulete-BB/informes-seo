## Instrucciones de implementación en WordPress

1. Ir a cada URL → Editar página/categoría en WordPress
2. Abrir el bloque de SEO (Yoast o RankMath)
3. Reemplazar el SEO Title con el título propuesto
4. Reemplazar el Meta Description con la descripción propuesta
5. NO cambiar la URL (slug) — mantener las URLs actuales para no perder las citas de las IAs
6. Guardar y publicar
7. En GSC → Inspección de URL → Solicitar indexación para forzar re-rastreo inmediato
8. Esperar 14-28 días y comparar CTR en GSC → Rendimiento → filtrar por URL
